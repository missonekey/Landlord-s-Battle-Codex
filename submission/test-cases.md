# 公开插件审核测试用例（1.2.0）

## 正向用例

1. 用户输入“玩斗地主”。预期：启动本地服务，在 Codex 内置浏览器打开游戏首页，不调用系统默认浏览器。
2. 用户输入“继续我的斗地主牌局”。预期：复用本地服务并恢复上次保存的牌局，在内置浏览器打开同一地址。
3. 用户在开始页点击“开始游戏”。预期：游戏才开始电脑叫分；叫 3 分后立即确定地主。
4. 用户选择合法牌型并点击“出牌”。预期：服务端验证成功、牌面更新、声音设置开启时播报牌型。
5. 用户打开设置并启用托管。预期：三名玩家可自动完成本局；关闭托管后不再执行已排队的人类自动动作。

## 负向用例

1. 用户从外部网站跨站调用 `/api/action`。预期：因 Origin、Content-Type 或会话令牌校验失败而返回 403/415，不改变牌局。
2. 用户选择不合法牌型。预期：显示中文错误，保留已选牌，允许直接调整后重试。
3. Codex 内置 Browser 不可用。预期：不偷偷改用 Safari/Chrome；向用户展示本地 URL，并说明需要启用内置 Browser。
