# 斗地主（Dou Dizhu）游戏

这是一个完整复刻标准「斗地主」规则的本地网页卡牌游戏插件。用户是主玩家（坐在下方），另外两名玩家由内置策略引擎 AI 扮演（左上为「上家」，右上为「下家」）。游戏完全离线运行，不需要网络。

## 启动步骤

1. 定位插件根目录：即包含 `.codex-plugin/plugin.json` 的目录（通常为 `~/plugins/doudizhu`）。
2. 从插件根目录运行启动脚本：
   ```bash
   cd <插件根目录>
   python3 scripts/start_game.py
   ```
3. 脚本会**立即返回**（守护进程模式，不要等它退出）：它会在后台启动游戏服务器、自动打开浏览器，并打印访问地址（默认 `http://127.0.0.1:8765`）。
4. 告诉用户：游戏已在浏览器中打开；若浏览器没有自动弹出，请手动访问脚本输出的地址。
5. 若输出「斗地主游戏已在运行」，说明服务器之前已启动，本命令只是重新打开了浏览器——直接告诉用户刷新或访问该地址即可。
6. 用户之后想再次进入游戏：再次运行 `python3 scripts/start_game.py`，或直接刷新浏览器页面（牌局状态保存在本地服务器中，刷新不丢局）。

## 停止服务器（可选）

```bash
python3 scripts/stop_game.py
```

## 游戏玩法说明（转告用户）

- **叫地主阶段**：点击「不叫 / 1分 / 2分 / 3分」表态，必须高于当前最高分才能叫；两家都不叫后叫分最高者成为地主；三人都不叫则重新发牌。
- **出牌阶段**：点击手牌选中（可多选），点「出牌」打出；点「不出」过牌；点「提示」让 AI 建议一种出法。
- **牌型**：单张、对子、三张、三带一、三带二、顺子（≥5 张）、连对（≥3 对）、飞机（带单/带对）、四带二（带两张单或两对）、炸弹、王炸。
- **翻倍**：每出一个炸弹或王炸 ×2；地主春天（农民没出过任何牌）×2；农民反春（地主只出过一手牌）×2。
- **结算**：地主赢：每个农民输 叫分×倍数，地主得两份；农民赢则反过来。
- **界面**：右上角「新一局」随时重开；「设置」可调 AI 出牌速度、游戏声音与托管模式。手机支持横竖屏。
- **选牌**：点击切换或左右拖动累加选牌；左键单击空白处出牌，左键双击空白处不出。非法出牌会保留选择。键盘可用 Tab 切换、空格或回车选牌。

## 故障排查

- `python3` 不存在：请先安装 Python 3（macOS 可运行 `xcode-select --install`）。
- 浏览器未自动打开：手动访问脚本打印的 URL。
- 页面报错或卡住：刷新浏览器页面（游戏状态在本地服务器，刷新不丢局）。
- 启动失败：脚本会打印错误并给出日志路径（`/tmp/doudizhu_server.log` 附近），检查日志后再试。
- 想停止游戏：`python3 scripts/stop_game.py`。
