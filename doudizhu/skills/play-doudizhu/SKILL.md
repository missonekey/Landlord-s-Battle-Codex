# 斗地主（Dou Dizhu）游戏

这是一个遵循标准叫分与出牌规则的本地网页卡牌游戏插件。用户是主玩家（坐在下方），另外两名玩家由内置策略引擎 AI 扮演（左上为「上家」，右上为「下家」）。游戏完全离线运行，不需要网络。

## 启动步骤

1. 定位插件根目录：即包含 `.codex-plugin/plugin.json` 的目录（通常为 `~/plugins/doudizhu`）。
2. 从插件根目录运行启动脚本；不要让脚本调用系统默认浏览器：
   ```bash
   cd <插件根目录>
   python3 scripts/start_game.py --no-browser
   ```
3. 脚本会**立即返回**（守护进程模式，不要等它退出），并打印 `CODEX_GAME_URL=http://127.0.0.1:<port>/`。
4. 必须使用 Codex 的内置 Browser 打开 `CODEX_GAME_URL`。不要调用 `open`、`webbrowser.open`、Safari、Chrome 或其它系统浏览器。
5. 若内置 Browser 不可用，明确告诉用户并提供脚本输出的本地 URL；不要擅自换用外部浏览器。
6. 若输出「斗地主游戏已在运行」，复用该地址并在内置 Browser 打开即可。
7. 用户之后想再次进入游戏：再次运行启动脚本并打开输出地址。牌局保存在插件数据目录，刷新或重启本地服务后仍可继续。

## 停止服务器（可选）

```bash
python3 scripts/stop_game.py
```

## 游戏玩法说明（转告用户）

- **叫地主阶段**：点击「不叫 / 1分 / 2分 / 3分」表态，必须高于当前最高分才能叫；两家都不叫后叫分最高者成为地主；三人都不叫则重新发牌。
- **出牌阶段**：点击手牌选中（可多选），点「出牌」打出；点「不出」过牌；点「提示」让 AI 建议一种出法。
- **牌型**：单张、对子、三张、三带一、三带二、顺子（≥5 张）、连对（≥3 对）、飞机（带单/带对）、四带二（带两张单或两对）、炸弹、王炸。
- **翻倍**：每出一个炸弹或王炸 ×2；地主春天（农民没出过任何牌）×2；农民反春（地主只出过一手牌）×2。
- **结算**：地主赢：每个农民输 叫分×倍数，地主得两份；农民赢则反过来。
- **界面**：右上角「新一局」随时重开；「设置」可调 AI 出牌速度、声音与托管模式。

## 故障排查

- `python3` 不存在：请先安装 Python 3（macOS 可运行 `xcode-select --install`）。
- 内置 Browser 未打开：使用 Codex Browser 打开脚本打印的 `CODEX_GAME_URL`；不要改用系统默认浏览器。
- 页面报错或卡住：刷新浏览器页面（游戏状态在本地服务器，刷新不丢局）。
- 启动失败：脚本会打印错误并给出日志路径（`/tmp/doudizhu_server.log` 附近），检查日志后再试。
- 想停止游戏：`python3 scripts/stop_game.py`。
